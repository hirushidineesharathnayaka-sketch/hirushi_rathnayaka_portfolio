# Hirushi Rathnayaka — Portfolio

A responsive, one-page portfolio site built with plain HTML and CSS. It can be published free with GitHub Pages.

## Preview on your laptop

1. Download or copy this folder to a place you can find, such as `Documents`.
2. Open Visual Studio Code, then choose **File → Open Folder** and select `hirushi-portfolio`.
3. In the VS Code Explorer, right-click `index.html` and choose **Open with Live Server** if you have the Live Server extension. If not, open `index.html` in your web browser directly.
4. To change text, edit `index.html`. To change colours, spacing or layout, edit `style.css`. Save and refresh the browser.

PyCharm can also open and edit these files. VS Code is a little simpler for this small static website.

## Publish it on GitHub Pages

### 1. Create a GitHub account

Go to [github.com](https://github.com/) and create an account if you do not already have one. Pick a professional username you are happy to share on your CV and LinkedIn. Add a profile photo, your name, a short bio such as **Computer Science undergraduate | Seeking a 2027 placement in software development or AI**, and your LinkedIn URL.

### 2. Create the portfolio repository

1. Sign in to GitHub and click **New repository** (or the **+** button, then **New repository**).
2. Name it `hirushi-rathnayaka-portfolio`.
3. Set it to **Public** so employers can view the source.
4. Select **Add a README file**, then click **Create repository**.

### 3. Add the website files

1. In the new repository, select **Add file → Upload files**.
2. Open the portfolio folder on your laptop and select `index.html`, `style.css`, and `README.md` (upload the files themselves, not just the folder).
3. Drop them into the GitHub upload area.
4. At the bottom, click **Commit changes**. A commit is a saved version of your files.

### 4. Turn on GitHub Pages

1. In the repository, open **Settings**.
2. In the left menu, select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then select **Save**.
5. Wait a minute or two and refresh the Pages settings. GitHub will show your live website address. It should look like `https://YOUR-USERNAME.github.io/hirushi-rathnayaka-portfolio/`.
6. Open that address on your phone and laptop to check it. If you edit the site later, upload the changed file and commit it; Pages will update automatically.

If you prefer the shorter address `https://YOUR-USERNAME.github.io/`, create a repository named exactly `YOUR-USERNAME.github.io` (replace that with your actual GitHub username), and upload the site files to that repository instead.

## Add it to LinkedIn

1. Open your LinkedIn profile and choose **Add profile section → Recommended → Add featured** (or use **Add profile section → Additional → Websites**, depending on the version of LinkedIn).
2. Add the GitHub Pages website address and give it a clear title such as **Portfolio — Software, Data & AI Projects**.
3. Add your GitHub profile address under **Contact info** or **Websites** as well.
4. You can also add the portfolio link to the top of your CV once the site is live.

## Before you share it with employers

- Check that each description matches work you can explain in an interview.
- Add links to project code or reports only after you have reviewed them and made them safe to share publicly. Do not upload university work that your course asks you to keep private.
- This version uses your LinkedIn URL and university email from your CV. Review those details before publishing; anything on a public website can be copied or indexed.
- Your CV lists the projects and coursework, but not public GitHub repositories for them yet. The project cards are informational until you add links to code or demos.
